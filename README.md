# NC Writer – Swine Farm Audit

WebApp สำหรับช่วย Auditor เรียบเรียงรายงานความไม่สอดคล้อง (NC) จากองค์ประกอบ 3 ส่วน:

1. Requirement — ข้อกำหนด
2. Objective Evidence — หลักฐานที่เป็นข้อเท็จจริง
3. Statement of Nonconformity — ข้อสรุปความไม่สอดคล้อง

## ความสามารถ

- แบบฟอร์มภาษาไทยที่แบ่งตามโครงสร้าง NC
- ประกอบข้อความ NC ฉบับสมบูรณ์อัตโนมัติ
- เตือนคำที่เป็นความคิดเห็น การคาดเดา สาเหตุ หรือแนวทางแก้ไข
- คัดลอกข้อความ ดาวน์โหลดไฟล์ `.txt` และพิมพ์/บันทึก PDF
- บันทึกแบบร่างในเบราว์เซอร์เครื่องที่ใช้งาน
- รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
- ไม่มีฐานข้อมูลและไม่ส่งข้อมูลออกจากเบราว์เซอร์

## วิธีเปิดใช้งานบน GitHub Pages

1. สร้าง Repository ใหม่ แนะนำชื่อ `swine-farm-nc-writer`
2. อัปโหลด `index.html`, `README.md` และ `.nojekyll` ไว้ที่หน้าแรกของ Repository
3. เปิด `Settings` → `Pages`
4. ที่ `Build and deployment` เลือก `Deploy from a branch`
5. เลือก Branch `main` และ Folder `/ (root)` แล้วกด `Save`
6. รอ GitHub สร้างลิงก์เว็บไซต์ แล้วเปิดใช้งานจาก URL ที่ GitHub แสดง

## การใช้งาน

1. กรอกแหล่งอ้างอิง เลขข้อ และข้อความข้อกำหนด
2. เลือกวิธีตรวจสอบ แล้วกรอกวัน เวลา สถานที่ ขอบเขต และข้อเท็จจริงที่ตรวจพบ
3. ตรวจคำเตือนจากระบบ
4. กด `ประมวลผลข้อความ NC`
5. ตรวจทานผลลัพธ์ก่อนคัดลอกหรือออกรายงาน

## ข้อจำกัด

เครื่องมือนี้ช่วยจัดโครงสร้างและเรียบเรียงข้อความ แต่ไม่ได้ยืนยันว่าข้อกำหนดที่นำมาอ้างเป็นฉบับล่าสุดหรือใช้ได้กับเหตุการณ์นั้น ผู้ตรวจต้องตรวจสอบเลขข้อ เนื้อหาข้อกำหนด และหลักฐานก่อนนำไปใช้จริง
